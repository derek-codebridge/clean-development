# Support

Use GitHub Discussions for setup questions and design conversations once Discussions is enabled. Use GitHub Issues for reproducible bugs and focused feature requests.

Include the `clean-development status --json` and `clean-development doctor --json` output after removing personal paths if needed. Do not paste credentials, private repository names, complete command histories, or agent transcripts.

Security reports belong in the private route described in [SECURITY.md](SECURITY.md), not Discussions or public issues.

This is a community open-source project with no guaranteed response time or commercial support agreement.
