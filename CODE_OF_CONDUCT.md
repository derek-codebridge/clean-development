# Code of conduct

Clean Development should be a practical, welcoming project.

Be respectful, assume good faith, keep criticism about the work, and make room for people with different experience levels and backgrounds. Harassment, threats, personal attacks, discrimination, doxxing, sexualized conduct, and sustained disruption are not accepted in project spaces.

Maintainers may edit or remove contributions and restrict participation when needed to protect the community. Enforcement should consider context, impact, prior behavior, and a proportionate path back where appropriate.

For ordinary moderation, contact the repository maintainers. For a sensitive report, use the private contact route listed on the [Magrathean UK GitHub profile](https://github.com/magrathean-uk); do not publish personal details in an issue. Good-faith reports will be handled as privately as the platform allows. Retaliation against a reporter is not accepted.

This policy applies in repository discussions, issues, pull requests, community spaces, and when someone officially represents the project.
