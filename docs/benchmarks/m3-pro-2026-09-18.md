# Shim overhead development snapshot

Date: 18 September 2026  
Machine: Apple M3 Pro MacBook Pro, 36 GB  
OS: macOS 27.0, arm64  
Node: 26.8.2  
Command: `npm run benchmark:overhead`

The benchmark invokes a no-op fake `cargo` executable directly and through a materialized clean-development shim. It warms both paths, alternates direct and routed samples, and does no network or compilation.

## Corrected paired-overhead samples

On 19 September the benchmark was corrected to subtract each routed sample from its paired direct sample before calculating the median and p95. Four 100-iteration runs with the same machine, OS, and Node version produced:

| Sample | Direct median | Routed median | Added median | Added p95 |
|---|---:|---:|---:|---:|
| Paired run 1 | 3.43 ms | 55.30 ms | 51.71 ms | 56.65 ms |
| Paired run 2 | 3.16 ms | 53.42 ms | 50.23 ms | 52.32 ms |
| Paired run 3 | 3.18 ms | 53.75 ms | 50.57 ms | 52.96 ms |
| Paired run 4 | 3.56 ms | 55.56 ms | 52.10 ms | 59.27 ms |

These development samples are below the provisional 75 ms p95 ceiling, while the 50 ms optimization target remains unmet. Release acceptance still needs repeated measurements on supported Node 20, 22, and 24, including cold starts, system-load variance, and real short and long build commands.
