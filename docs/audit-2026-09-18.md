## Fix made during the audit

An explicit `setup --agents` selection now deactivates previously owned native Claude, Codex, and Grok integrations omitted from the new selection. It preserves unrelated configuration and leaves shared launchers available. A regression test covers the transition from all three native routes to Claude only.

The Codex repo marketplace also now uses the current local `source` / `path` schema, and `scripts/check.mjs` rejects a regression to the old form.

## Remaining release gates

- baseline/enabled model-facing request captures for token-neutrality evidence;
